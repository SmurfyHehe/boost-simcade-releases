# Boost Simcade: game downloads

This page only holds the game's builds. There is no code here.

## Install (first time)

1. Open [Releases](../../releases) and take the newest build marked **Latest**.
2. Download **`BoostSimcade-build-<number>.zip`**. Do not use "Source code": it has no game in it.
3. Unzip it anywhere and start `BoostSimcade.exe`.
4. Windows may show "Windows protected your PC". Click **More info**, then **Run anyway**. `HOW-TO-INSTALL.txt` in the zip shows this step.

## Updates

You only download once. The game checks for updates on the title screen and installs them at its next start.

## Found a problem?

Open [Issues](../../issues), press **New issue**, choose **Bug in the game** and fill in the short form. The build number is on the title screen, in the pause menu and in Settings.
